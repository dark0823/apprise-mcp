30-Second Setup

Connect in One Copy-Paste

Add this snippet to your claude_desktop_config.json:

{
  "mcpServers": {
    "apprise-mcp": {
      "command": "python",
      "args": ["d:/your-path/apprise-mcp/server.py"]
    }
  }
}

Go to Settings → Features → MCP → + Add New MCP Server:

Name: apprise-mcp
Type: command
Command: python "d:/your-path/apprise-mcp/server.py"

Paste into your cline_mcp_settings.json:

{
  "mcpServers": {
    "apprise-mcp": {
      "command": "python",
      "args": ["d:/your-path/apprise-mcp/server.py"]
    }
  }
}

Run from any terminal, bash script, or CI/CD runner:

# Send single alert
python cli.py notify -u "tgram://BOT_TOKEN/CHAT_ID" -t "Build Done" -b "Deployed."

# Multi-channel parallel broadcast
python cli.py notify -u "tgram://..." -u "discord://..." -t "Sirens" -b "Alert!" --json

Install skill into OpenClaw or AutoGPT from skills/openclaw/SKILL.md:

# OpenClaw Manifest Entrypoint:
{
  "skill": "apprise-notifier",
  "exec": "python cli.py notify",
  "mcp": "server.py"
}
